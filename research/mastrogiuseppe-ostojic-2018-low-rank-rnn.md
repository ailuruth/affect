## The object
- Rate network ẋ_i = −x_i + Σ_j J_ij φ(x_j) + I_i, φ = tanh, with **J = gχ + P**: χ random (variance 1/N), P structured and low-rank, P = Σ_{k=1}^r m^(k) n^(k)ᵀ / N.
- m^(k) and n^(k) are the **right and left connectivity vectors**; for rank one, "the only non-zero eigenvalue of P is given by the scalar product mᵀn/N", with right/left eigenvectors m and n. In the full J this appears as one **outlier eigenvalue** outside the random bulk (radius set by g).
- **Mean-field result:** the mean input is μ_i = κ m_i + I_i with κ = (1/N) Σ_j n_j [φ_j]. Activity lies on average in span(m^(1..r), I). "The right-connectivity vector m determines the output pattern of network activity, while the left-connectivity vector n instead selects the inputs that give rise to outputs along m."
- **Two regimes.** (a) m ⊥ n: no spontaneous structure; an input with overlap on n produces graded activity along m. (b) mᵀn/N large enough (> 1): bistable structured activity; an input along n can remove one of the two states (a nonlinear switch).
- **Time scales from overlaps.** In the noisy-detection network, the integration time constant "is set by the connectivity strength, i.e. the overlap between the left- and right-connectivity vectors m and n … Arbitrarily large timescales can be obtained by adjusting this overlap close to the bifurcation value."
- **Contextual control without gating inputs.** A modulatory input along the *overlap direction* of m and n shifts the threshold of the bistability; context A/B inputs along the two overlap directions switch which stimulus–response association is active (an XOR-like task in a rank-two net).
- **Ring attractor from symmetry.** With symmetric overlaps (m^(1)ᵀn^(1) = m^(2)ᵀn^(2)), rank two gives a continuous ring attractor in the m^(1)–m^(2) plane; an extra common component along the readout breaks it into two fixed points, leaving a slow manifold near the ring. The authors note Mante et al.'s trained net was either two line attractors or a ring depending on training.
- **Mixed selectivity is generic**: random m, n, I make every unit mixed while the dynamics stay r+1 dimensional; readout error falls as 1/√N.
- **Testable prediction:** units with large loadings on dominant PCs (when those come from recurrence, not input) should be more strongly connected to each other.

## What it means for the design
1. **The mathematical object for a population code of persistent internal states** (the question asked of Nair, Vinograd and insula work): a high-dimensional network whose connectivity is random plus low-rank, with the slow states living in span(m), the input selection set by n, and time constants set by the overlaps nᵀm relative to the bifurcation value. A rich latent (N large, mixed selectivity) with low-dimensional persistent structure, and temperament as one structural number (the leading overlap), matching Nair et al.'s r² = 0.77 between leading time constant and aggressiveness.
2. **Reflex-to-temperament from structure:** the random bulk gives fast, high-dimensional transients (τ of single units); each low-rank pair gives a mode whose time constant is set by its distance from bifurcation. A ladder of overlaps is a ladder of time scales without any per-unit time constant.
3. **The input–selection split is explicit and per vector:** the partner channel j enters along I_j; how much it drives persistent mode k is the overlap n^(k)ᵀ I_j / N. A per-channel ceiling is a bound on that overlap (with the 1/τ_k scaling derived in mante-2013-selection-vector.md).
4. **Caveat the authors give themselves:** the theory assumes P weak and independent of χ; trained nets (FORCE, ESN) need not satisfy that, and "the random part of the connectivity may play an important role during training". For a ceiling stated on n, the random part shifts the effective left eigenvector, so a ceiling on n is a ceiling on the outlier eigenvector only approximately (error growing with g).

## Verdict
- **adopt (as the object for (b): persistent internal states as low-rank structure in a high-dimensional random network).** It is an existing framework (low-rank RNN; Hopfield, FORCE and ESN are special cases, as the authors say), so a core built on it is a recombination; the value is a closed-form link from connectivity overlaps to time scales, input selection and contextual switching.
