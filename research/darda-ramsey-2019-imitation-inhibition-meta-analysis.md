# The inhibition of automatic imitation: a meta-analysis and synthesis of fMRI studies (Darda & Ramsey)

Kohinoor M. Darda & Richard Ramsey, *NeuroImage* 197:320–329, 2019, doi:10.1016/j.neuroimage.2019.04.059 (bioRxiv 10.1101/334938; data on NeuroVault collection 5377).

## What was read
**Not the paper.** bioRxiv, the Bangor repository and ScienceDirect were blocked by this session's network policy. What I had: abstract-level search excerpts and a 2024 review chapter's summary of the result. **The number of studies, the thresholds and the cluster coordinates were not seen.**

## The computation, precisely
- **Method (excerpts):** multilevel kernel density analysis (MKDA) of fMRI studies using the imitative stimulus–response compatibility contrast (incongruent > congruent). The authors tested how far a theory-of-mind network (mPFC, rTPJ), a multiple-demand (MD) network, or both are engaged.
- **Result (as summarised by later work):** consistent engagement of the domain-general **multiple-demand network** (dorsolateral frontoparietal cortex) for the imitative compatibility effect, **but not of mPFC or rTPJ**. The authors read this as limited support for a domain-specific self–other control system.

## What it means for the designs
- **The resolving step is generic conflict control.** Across studies, what reliably activates when seen and intended actions conflict is the same machinery that resolves any response conflict. Self–other-specific regions show up in some studies (Brass, Spengler) and in causal stimulation (Sowden; Hogeveen), but not consistently.
- **The computation splits in two.** (1) A source signal: which component of the motor code is other-driven. This may be small, task-dependent and cheap. (2) A **generic** conflict-resolution step that suppresses the losing response once the source is known. For a design, the attribution operator is the only special part; suppression can be the same competitive or normative dynamics used for any action selection. No dedicated "anti-copy" module is needed.
- **A caution:** if copying control is mostly generic conflict control, it acts only when the copy *conflicts* with an active own intention. When the agent has no competing intention (a neutral resting face), nothing resists the mirrored input. **The guard is weakest exactly when the agent is idle**, which is when an avatar's face most often copies. A design must give the resting face its own intention (homeostatic or expressive set point) so that conflict exists.
- **Time scale:** within trial.

## Verdict
**adopt (as a constraint; abstract-level).** Do not build a dedicated self–other inhibitor; build attribution plus ordinary selection, and make sure there is always an own intention to select for.
