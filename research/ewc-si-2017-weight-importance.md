## Claims
- EWC: forgetting happens "because the weights in the network that are important for task A are changed to meet the objectives of task B". The fix is to slow learning "on certain weights based on how important they are to previously seen tasks", via a quadratic "spring anchoring the parameters to the previous solution" whose stiffness is the diagonal Fisher.
- EWC rejects the replay route. Replaying stored episodes ("system-level consolidation") "is impractical for learning large numbers of tasks" because memory "would require the amount of memories being stored and replayed to be proportional to the number of tasks".
- EWC grounds this in Bayes: "the network parameters are tempered by a prior which is the posterior distribution on the parameters given data from previous task(s)", which gives "fast learning rates on parameters that are poorly constrained by the previous tasks, and slow learning rates for those which are crucial".
- EWC's own stated weakness: the diagonal-Fisher Laplace point estimate "under-estimates parameter uncertainty"; it is "over-confident about certain parameters being unimportant".
- SI: each synapse becomes a 3-D dynamical system that stores its current value, a reference value and an "importance". The importance "can be computed efficiently and locally at each synapse during training". Unlike EWC, which "relies on a point estimate of the diagonal of the Fisher information metric at the final parameter values ... computed during a separate phase at the end of each task", SI computes importance "online and along the entire learning trajectory".
- SI says consolidation also helps transfer. Networks with consolidation "generalize better on new tasks with limited data".
- Huszár: EWC's multiple penalties are "not well justified and might lead to double-counting data from earlier tasks". A consistent recursive Laplace approximation keeps "only a single penalty ... anchored at the most recently learned parameters". Multiple penalties "introduce an unwanted systematic bias favouring tasks learned earlier on".

## Evidence (numbers)
- EWC, permuted MNIST. Fully connected ReLU networks: 2 layers of width 400, learning rate 10⁻³, 20 epochs per task (Fig. 2A), up to 6 layers in other panels. Plain SGD forgets task A. A uniform L2 penalty keeps A but "task B cannot be learned properly". EWC learns A, B and C. For dropout+SGD (dropout 0.2 on input, 0.5 on hidden layers, early stopping, 50 random hyperparameter draws), the authors cite prior success on only "up to two random permutations". EWC holds "a large number of tasks ... with only modest growth in the error rates" (figure only; no table).
- EWC Fisher overlap: overlap is 1 − ½‖F̂₁^½ − F̂₂^½‖²_F on trace-normalised Fishers. Overlap is high throughout the network for similar tasks (an 8×8 pixel permutation). For dissimilar tasks (26×26), it drops in early layers while "layers ... closer to the output are indeed being reused".
- EWC, Atari. Each experiment uses 10 games drawn from a pool of 19 that DQN learns to human level within 50M frames: 10 sets × 4 seeds. The score is the sum of human-normalised scores, each capped at 1 (maximum 10). With plain SGD the total "remains below one" and the agent "never learns to play more than one game". With EWC the agent learns several games but stays below ten separate DQNs. Giving the agent the true task label instead of the inferred one helped "only modest[ly]". Hyperparameters: Fisher multiplier λ = 400; the Fisher comes from 100 minibatches of the replay buffer at each task switch; EWC applies only after 20M frames on a game; replay memory 50,000 (Table 2), described as 5×10⁵ in the prose. The two values are inconsistent in the source.
- EWC perturbation test (Fig. 3C): the agent is more robust to noise shaped by (F + λI)⁻¹ than to isotropic noise. Noise in the Fisher nullspace hurts as much as inverse-Fisher noise, which is the evidence for the over-confidence weakness.
- SI, split MNIST: 5 two-digit tasks, MLP 2×256, multi-head, ξ = 10⁻³, c = 1, Adam η = 10⁻³, batch 64, 10 epochs, n = 10. Without consolidation the first two tasks fall "back to chance levels". With it there is "only minor degradation" (figure only).
- SI, permuted MNIST: MLP 2×2000, ξ = 0.1, c = 0.1 (coarse grid search), batch 256, 20 epochs, Adam state kept across tasks. Accuracy over 10 tasks stays in the figure's zoom band of 0.97-1.00, "comparable" to EWC and "slightly worse" than joint training. With consolidation the ω are "largely uncorrelated across tasks" in layer 2. Without it they become correlated, which the authors call "likely ... the cause of catastrophic forgetting".
- SI, split CIFAR-10 → 5 × CIFAR-100: c = 0.1, n = 5. With consolidation, validation accuracy beats fine-tuning on every task except the last. It matches or beats from-scratch training except on CIFAR-10 itself. Appendix B (CIFAR-10 split in two): consolidation gives ≈4.5% better validation accuracy on the new Task B, "consistently for ... 0.1 < c < 10".

## Mechanism
EWC (diagonal Laplace):
- Posterior factorisation: log p(θ|D) = log p(D_B|θ) + log p(θ|D_A) − log p(D_B). Huszár corrects the last term to log p(D_B|D_A); it is irrelevant to the gradient.
- Loss on task B: L(θ) = L_B(θ) + Σᵢ (λ/2) Fᵢ (θᵢ − θ*_A,ᵢ)².
- Fisher (SI App. C): F = E_{x∼D, y∼p_θ(y|x)}[∇θ log p_θ(y|x) ∇θ log p_θ(y|x)ᵀ]. The empirical Fisher F̄ = E_{(x,y)∼D}[g gᵀ] uses data labels. EWC keeps only diag(F). It is computed after training on a task, at θ*_A.
- More than two tasks. EWC as published adds one penalty per task, each anchored at that task's θ*. Huszár's recursive Laplace gives a single penalty, θ*_T = argmin −log p(D_T|θ) + ½ Σᵢ (Σ_{t<T} λ_t F_{t,i} + λ_prior)(θᵢ − θ*_{S,i})², anchored at the latest solution S, with precision summed over tasks. Its storage is constant in the number of tasks. λ_t stands in for the sample size N_t, because H ≈ N·F + H_prior.
- Atari extras, which matter for us:
  - Per-context gains and biases on every layer: yᵢ = (Σⱼ Wᵢⱼ xⱼ + bᵢᶜ) gᵢᶜ.
  - The context c is inferred as the hidden state of an HMM with p(c, t+1) = Σ_{c'} p(c', t) Γ(c, c'), where Γ = δ(1−α) + (1−δ)α and α = 1/t.
  - Each context has a Dirichlet-multinomial generative model of the (downscaled 42×42) observation. In each window W the best-fitting model keeps its update and the others revert. A held-out uniform model that wins creates a new context ("forget-me-not").
  - Each inferred task gets its own short-term replay buffer. The paper describes this as "memory on two time-scales": replay for short-term decorrelation, EWC for consolidation across tasks.

SI (path-integral importance):
- Per-parameter credit along the trajectory: ω_k^μ = −∫_{t_{μ−1}}^{t_μ} g_k(θ(t)) θ'_k(t) dt. In practice this is the running sum of −g_k·Δθ_k at every optimiser step. Summed over k, the ω equal the total loss drop, since the gradient field is conservative.
- Consolidated strength: Ω_k^μ = Σ_{ν<μ} ω_k^ν / ((Δ_k^ν)² + ξ), where Δ_k^ν = θ_k(t_ν) − θ_k(t_{ν−1}) is the net move during task ν and ξ is a damping constant.
- Loss: L̃_μ = L_μ + c Σ_k Ω_k^μ (θ̃_k − θ_k)², with θ̃ = θ(t_{μ−1}). The surrogate is exact only for two tasks. c = 1 would weigh old and new equally if the path integral were exact. SGD noise makes ω overestimate, so c < 1 in practice.
- Bookkeeping: "ω_k are updated continuously during training, whereas ... Ω and ... θ̃ are only updated at the end of each task. After updating the Ω, the ω are set to zero." SI is online in credit but still needs a boundary to consolidate.
- Theory: on a quadratic E = ½(θ−θ*)ᵀH(θ−θ*) under gradient flow, Q = τ∫θ'θ'ᵀdt averages to ⟨Q⟩ = (σ²/2)H. When H is diagonal or rank 1, the normalised Ω recovers the Hessian exactly. The empirical Fisher at a quadratic's minimum is 0, but the path integral is not.

Differences, in one line each:
- When importance is computed. EWC: offline, at the task's end, as local curvature at a single point. SI: online, accumulated along the whole path.
- Task boundaries. Both need one to set the anchor and freeze importance. EWC also needs one to trigger the Fisher pass. In Atari, EWC paired this with an inferred context, not a given one.
- Cost. EWC needs an extra pass, and sampled-label backprop for the true Fisher. SI adds three numbers per weight and no extra gradients.
- Grounding. EWC is a principled Laplace posterior in the two-task case, and stays principled beyond two tasks only in Huszár's single-penalty form. SI is a heuristic surrogate beyond two tasks.

## Runs on this Mac without a GPU?
Yes. This is our judgment. Both are O(#params) per step. SI adds ω, θ̃ and Ω buffers, so roughly 3× parameter memory. Diagonal EWC adds a nightly pass over some replay minibatches. For a small engine both cost almost nothing next to the forward model.

## Implications for the engine (our inferences)
- **The day is the task, and sleep is the boundary.** Both methods consolidate at a boundary. A life of a few hours a day gives one for free: the offline period between sessions. Map SI onto it. ω_k accumulates online during the session, as a per-synapse eligibility or "tag" in the sense of Redondo & Morris, whom SI cites. At night, Ω_k += ω_k/(Δ_k² + ξ), the anchor θ̃ is set to the end-of-night weights, and ω is reset. This needs no task labels, which matches the brief's setting, where no one tells the engine that a "task" changed.
- **Temperament as accumulated stiffness.** Under Huszár's consistent recursion, total precision Σ_t λ_t F_t only grows. Parameters that every day has relied on stiffen without bound. That is a mechanistic reading of "a stable temperament forms over months": the variance of slow parameters shrinks roughly as 1/(number of days that used them). The flip side is that plasticity dies unless precision decays. Online EWC variants add a decay γ; that comes from Progress & Compress, which we have not read. A decay rate is a free parameter that Principle 10 would need derived. In a Bayesian core it is the prior on parameter drift, i.e. the assumed rate at which the operator and the world change.
- **Scarce data sets the stiffness by itself.** Huszár shows λ_t stands in for N_t, since H ≈ N·F. Days with little interaction should add little precision. Days with a lot should add more. A principled engine should therefore not hand-tune λ: it should be the amount of evidence that day. The EWC authors' finding that a diagonal Laplace point estimate is over-confident is worse with little data: Laplace underestimates posterior entropy at finite N. Expect early-life Fishers to be noisy and to over-protect.
- **A partner-specific mapping without forgetting others.** The most useful part of the EWC paper for us is the Atari agent, not MNIST: shared weights protected by EWC, plus per-context gains and biases, plus a non-parametric HMM that creates a new context when a fresh generative model explains the data better. Read "context" as "who I am with". The relationship becomes a small set of partner-indexed multiplicative gains, in the spirit of FiLM, on a shared temperament network. That set is created by inference, not by a label, and is cheap to keep for many partners. The Fisher-overlap result predicts how sharing falls out: early perceptual layers separate when partners differ in input statistics, while layers near the output (the expression and action repertoire) stay shared. True labels helped only "modest[ly]" over inferred ones, which is encouraging for unlabelled partner inference.
- **What state-tagging adds that importance regularisers cannot.** EWC and SI protect *parameters*, weighted by how much the loss used them. They are blind to *which internal state* an experience happened in. A state tag can enter in two places:
  - (a) ω accumulation. Weight −g·Δθ by an internal-state gain at encoding time. Credit then flows to synapses used during high-arousal or high-need moments, which is a synaptic analogue of McGaugh-style modulation.
  - (b) The night's Fisher pass. Compute F from replayed samples drawn in proportion to their tags, so the precision protects what mattered affectively.
  Ablating either one is a clean test: replace the tag with uniform weights. Neither is in the papers. The objective must license both: a precision-weighted likelihood in which the tag *is* a precision term would derive (b) directly.
- **Fast/slow interaction.** EWC's Atari agent already has two stores: per-context replay buffers (fast, episodic) and EWC (slow, synaptic). SI has two variables per synapse: ω (fast, reset nightly) and Ω (slow, cumulative). Neither paper replays the past to the slow store; EWC explicitly avoids that. The CLS view, and Rolnick et al. 2019, say replay does better. Treat importance regularisers as a complement that guards against drift between replays, not as the consolidation mechanism.
- **Hazard for S4 and model upgrades.** Anchors live in parameter space. Swapping the face model (S4) or upgrading the conceptual layer (S6) invalidates θ̃ and F for the changed parts. Whatever must survive an upgrade (temperament, relationship) cannot live only as an EWC anchor. It has to be re-derivable from replay or stored in coordinates that do not change, such as the innate body variables.

## Verdict: watch. Adopt only the single-anchor online-Laplace form, and only if the chosen core is Bayesian or variational. Reject multi-penalty EWC and reject SI as core components.
- Principle 10: a quadratic posterior penalty follows from a variational or Bayesian objective as the Laplace approximation of the previous posterior. It is then a derived component, with λ_t = N_t and an explicit drift prior, not a module. Multi-penalty EWC is not derivable (Huszár). SI's Ω is a heuristic beyond two tasks, though its ω is a good cheap online curvature proxy.
- Neither handles state tagging. Both need a boundary, which sleep supplies. Neither replaces replay. The per-context gain and bias plus an inferred-context HMM from the EWC Atari appendix is worth carrying into any candidate as the partner-specificity mechanism.
- Ablation predictions we could derive: setting precision to 0 (c = 0) should make temperament drift with each day's mood. Uniform tag weights in the Fisher pass should leave stability intact but remove the bias to protect what happened in salient states.
